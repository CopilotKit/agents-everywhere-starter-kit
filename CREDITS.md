# Sponsor credits and access

## OpenAI credits

OpenAI is the event's marquee sponsor. **An event-specific credit amount, redemption URL, or promo code was not published in the public handbook when checked on September 11, 2026.** Get the offer from the [official portal and handbook](https://sf.aitinkerers.org/hackathons/h_XWWQL5eKfJM/handbook), the opening-session instructions, or your local organizer.

When the organizer provides it:

1. Open the organizer's redemption link and follow that offer's instructions. Check its eligibility and expiration date.
2. Sign in to the OpenAI API account and organization you will use for the hackathon. Apply the offer to the intended organization as directed.
3. Check your [API billing overview](https://platform.openai.com/settings/organization/billing/overview) to confirm the grant appears before assuming it is available.
4. Create an [API key](https://platform.openai.com/api-keys) in the funded organization/project. Set `OPENAI_API_KEY` in the chosen template's ignored environment file.
5. Run the [small OpenAI test call](using-sponsor-tools.md#openai) and confirm it succeeds with your selected model.

Creating an API key does not redeem credits. Do not substitute ChatGPT credits for an API offer. If the grant is missing, check the account/organization and contact the organizer; do not assume a signup includes the event offer. [OpenAI's API billing guidance](https://help.openai.com/en/articles/8264644)
